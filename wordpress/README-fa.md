# پیاده‌سازی سایت «استودیو اثر» روی وردپرس فارسی + المنتور

این پکیج شامل همه‌چیزهایی است که برای بازسازی ۹ صفحه‌ی سایت استودیو اثر در وردپرس فارسی با المنتور لازم دارید.

## 📦 محتوای پکیج

```
wordpress/
├── README-fa.md                 ← همین راهنما
├── theme/                       ← قالب وردپرس (Theme) «Effect Studio»
│   └── effect-studio/           ← این پوشه را در wp-content/themes آپلود کنید
│       ├── style.css            ← استایل اصلی + تعریف قالب
│       ├── functions.php        ← تنظیمات، منوها، فونت، رنگ
│       ├── header.php           ← هدر اختصاصی (مطابق طراحی برند)
│       ├── footer.php           ← فوتر اختصاصی
│       ├── front-page.php       ← صفحه نخست (سازگار با المنتور)
│       ├── page.php / single.php / archive.php / index.php / search.php / 404.php
│       ├── rtl.css              ← استایل راست‌چین
│       ├── inc/                 ← customizer (رنگ/تلفن/ایمیل) + توابع کمکی
│       ├── template-parts/      ← اجزای حلقه محتوا
│       └── assets/              ← CSS، JS و محل فونت وزیرمتن
├── elementor-templates/         ← ۹ قالب قابل-ایمپورت المنتور (JSON)
│   ├── effect-studio-home.json          (صفحه اصلی)
│   ├── effect-studio-about-us.json      (درباره ما)
│   ├── effect-studio-academy.json       (آکادمی)
│   ├── effect-studio-course.json        (صفحه دوره)
│   ├── effect-studio-blog.json          (بلاگ)
│   ├── effect-studio-category.json      (دسته‌بندی بلاگ)
│   ├── effect-studio-post.json          (نوشته بلاگ)
│   ├── effect-studio-shop.json          (فروشگاه)
│   └── effect-studio-product.json       (صفحه محصول)
├── generate_templates.py        ← اسکریپت تولید قالب‌های المنتور (قابل استفاده مجدد)
└── assets/
    ├── logo.png                ← لوگوی برند (PNG)
    ├── logo.webp               ← لوگوی برند (WebP)
    └── effect-studio.css       ← پالت رنگ و فونت برند
```

## 🚀 گام ۱ — نصب وردپرس فارسی

1. وردپرس را روی هاست نصب کنید (یا از نصب‌کننده‌ی یک‌کلیکی هاست استفاده کنید).
2. بعد از نصب، زبان فارسی را فعال کنید:
   - مسیر: **Settings → General → Site Language → فارسی (فارسی)**
   - اگر «فارسی» در لیست نبود، بسته زبان را از **Dashboard → Updates → Install translations** بگیرید.
3. ساختار پیوند یکتا را روی «نام نوشته» بگذارید:
   - **Settings → Permalinks → Post name** و ذخیره کنید.

## 🎨 گام ۲ — نصب قالب وردپرس «Effect Studio» و المنتور

### ۲.۱ نصب قالب اختصاصی (پیشنهادی)

قالب `effect-studio` که در همین پکیج است، هدر و فوتر را **دقیقاً مطابق طراحی سایت** پیاده می‌کند و نیازی به Elementor Pro برای هدر/فوتر ندارید:

1. پوشه `wordpress/theme/effect-studio/` را در مسیر `wp-content/themes/` هاست آپلود کنید (یا فایل zip بسازید و از **Appearance → Themes → Add New → Upload Theme** نصب کنید).
2. از **Appearance → Themes** قالب **Effect Studio** را فعال کنید.
3. از **Appearance → Customize** رنگ‌های برند، شماره تلفن و ایمیل را تنظیم کنید.
4. از **Appearance → Menus** یک منو بسازید و به موقعیت «منوی اصلی» اختصاص دهید (تا قبل از آن، منوی پیش‌فرض برند به‌صورت خودکار نمایش داده می‌شود).

> 💡 اگر نمی‌خواهید از قالب اختصاصی استفاده کنید، می‌توانید قالب سبک **Hello Elementor** نصب کنید؛ اما در آن صورت هدر/فوتر را باید خودتان بسازید (یا با Elementor Pro Theme Builder).

### ۲.۲ نصب المنتور

1. المنتور (نسخه رایگان کافی است) را نصب و فعال کنید:
   - **Plugins → Add New → جستجوی "Elementor" → Install → Activate**

## 🌐 گام ۳ — فعال‌سازی راست‌چین (RTL) و فونت فارسی

1. **Customize → Additional CSS** (یا Elementor → Site Settings → Custom CSS) را باز کنید.
2. محتوای فایل `assets/effect-studio.css` را در آن جای‌گذاری کنید.
3. برای فونت فارسی، یکی از این دو راه:
   - افزونه **«فونت فارسی المنتور»** یا **«WP Persian Fonts»** را نصب کنید و فونت **وزیرمتن (Vazirmatn)** را انتخاب کنید؛
   - یا فونت وزیرمتن را از [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) دانلود و در قالب enqueue کنید.

## 📥 گام ۴ — ایمپورت قالب‌ها در المنتور

1. مسیر: **Templates → Saved Templates → Import Templates**
2. هر ۹ فایل JSON را یک‌جا انتخاب و ایمپورت کنید.
3. یک «صفحه» جدید بسازید (Pages → Add New)، سپس **Edit with Elementor** را بزنید.
4. در المنتور: آیکون پوشه (Add Template) → تب **My Templates** → قالب موردنظر را انتخاب و Insert کنید.

> ⚠️ نکته: قالب‌های المنتور شامل هدر و فوتر هستند؛ چون قالب `effect-studio` هم هدر/فوتر خودش را دارد، برای اینکه هدر/فوتر تکراری نشود، دو راه دارید:
> - (ساده‌تر) در قالب‌های المنتور، بخش هدر و فوتر (دو کانتینر اول و آخر) را حذف کنید تا فقط هدر/فوتر قالب نمایش داده شود؛ **یا**
> - هدر/فوتر قالب وردپرس را با Elementor Pro Theme Builder بسازید و بدنه صفحات را از قالب‌های المنتور بگیرید.

## 🔗 گام ۵ — اتصال صفحات (لینک‌ها)

در قالب‌ها لینک‌های داخلی به‌صورت اسلاگ نسبی نوشته شده‌اند. بعد از ساخت صفحات، این‌ها را با لینک واقعی صفحات خودتان جایگزین کنید (یا از Dynamic Tag → Internal URL در المنتور استفاده کنید):

| صفحه | اسلاگ پیشنهادی | فایل قالب |
|---|---|---|
| صفحه اصلی | `/` | effect-studio-home.json |
| درباره ما | `/about-us/` | effect-studio-about-us.json |
| آکادمی | `/academy/` | effect-studio-academy.json |
| دوره | `/academy/course/` | effect-studio-course.json |
| بلاگ | `/blog/` | effect-studio-blog.json |
| دسته‌بندی | `/category/technology/` | effect-studio-category.json |
| نوشته | `/blog/hyundai-elantra-2027/` | effect-studio-post.json |
| فروشگاه | `/shop/` | effect-studio-shop.json |
| محصول | `/shop/pegboard/` | effect-studio-product.json |

> 💡 ساده‌ترین راه برای جایگزینی همه‌ی لینک‌ها: در ویرایشگر المنتور، روی هر دکمه/لینک کلیک کنید و در پنل سمت چپ، فیلد Link را به آدرس صفحه‌ی مربوطه تغییر دهید.

## 🖼 گام ۶ — لوگو و تصاویر

- لوگوی برند در `assets/logo.png` و `assets/logo.webp` موجود است.
- آن را در **Media → Add New** آپلود کنید و در ویجت Image هدر (که فعلاً با `LOGO_URL` مشخص شده) جایگزین کنید.
- سایر تصاویر (نمونه‌کارها، اسلایدرها، عکس محصولات و دوره‌ها) را از فایل‌های HTML اصلی یا نسخه‌ی زنده‌ی سایت بردارید و در Media آپلود کنید.

## 📝 گام ۷ — منوی ناوبری (اختیاری اما پیشنهادی)

1. مسیر: **Appearance → Menus**
2. یک منو بسازید و این آیتم‌ها را اضافه کنید:
   استودیو اثر، درباره ما، خدمات اثر، بلاگ، فروشگاه، ارتباط با ما.
3. در المنتور، ویجت **Nav Menu** را جایگزین لینک‌های متنی هدر کنید و این منو را انتخاب کنید تا مدیریت آیتم‌ها از پیشخوان وردپرس انجام شود.

## 🧰 نکات تکمیلی

- **رنگ‌های برند** (برای هماهنگی سراسری):
  - بنفش اصلی: `#4a00a5`
  - بنفش تیره (هدر/فوتر): `#2d0065`
  - کهربایی (CTA): `#ffaa00`
  - متن اصلی: `#16161d`
- **فونت پیشنهادی:** وزیرمتن (Vazirmatn)
- برای فروشگاه واقعی (سبد خرید، پرداخت)، افزونه **ووکامرس (WooCommerce)** را نصب کنید و صفحات `فروشگاه` و `محصول` را با محصولات ووکامرس جایگزین کنید.
- برای دوره‌ها و ثبت‌نام، می‌توانید از افزونه‌های LMS مانند **LearnPress** یا **Tutor LMS** استفاده کنید.
