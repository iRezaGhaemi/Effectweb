# پیاده‌سازی سایت «استودیو اثر» روی وردپرس فارسی + المنتور

این پکیج شامل همه‌چیزهایی است که برای بازسازی ۹ صفحه‌ی سایت استودیو اثر در وردپرس فارسی با المنتور لازم دارید.

## ⚠️ مهم — دو روش استقرار (حتماً بخوانید)

این پروژه دو روش استقرار دارد. **بسته به هدف‌تان یکی را انتخاب کنید:**

| روش | پکیج | نتیجه | مناسب برای |
|---|---|---|---|
| **پیکسل‌پرفکت** | `effect-studio-pixel-perfect.zip` | ۱۰۰٪ دقیقاً مثل فایل‌های اصلی | وقتی ظاهر باید عیناً یکسان باشد |
| **وردپرس + المنتور** | `effect-studio-complete.zip` | نزدیک به طراحی، قابل ویرایش در پیشخوان | وقتی مدیریت محتوا/فروشگاه/بلاگ لازم است |

> **چرا دو روش؟** فایل‌های HTML شما خروجی استاتیک یک سایت Next.js هستند (با Tailwind CSS، تصاویر base64 و انیمیشن). المنتور موتور رندر خودش را دارد و بازسازی ۱۰۰٪ پیکسل‌پرفکت این صفحات در المنتور ممکن نیست. اگر «عیناً مثل فایل‌ها» می‌خواهید، از روش پیکسل‌پرفکت استفاده کنید؛ اگر قابلیت ویرایش می‌خواهید، المنتور را انتخاب کنید (با پذیرش اختلاف جزئی ظاهری).

### 🎯 روش پیکسل‌پرفکت (ساده‌تر و دقیق‌تر)

1. فایل `effect-studio-pixel-perfect.zip` را باز کنید.
2. همه فایل‌ها (شامل `index.html`) را در ریشه هاست (`public_html`) آپلود کنید.
3. تمام! سایت دقیقاً مثل فایل‌های اصلی نمایش داده می‌شود. بدون وردپرس.

### 🛠 روش وردپرس + المنتور (قابل ویرایش)

ادامه‌ی همین راهنما را دنبال کنید.

## 🚀 گام ۱ — نصب وردپرس فارسی

> ⚠️ **نکته حجم:** قالب با تصاویر واقعی حدود ۳ مگابایت است و از حد پیش‌فرض آپلود وردپرس (۲ مگابایت) بیشتر است. اگر آپلود از پیشخوان خطا داد، یا از **FTP / File Manager** هاست استفاده کنید یا حد آپلود را افزایش دهید.

1. وردپرس را روی هاست نصب کنید (یا از نصب‌کننده‌ی یک‌کلیکی هاست استفاده کنید).
2. بعد از نصب، زبان فارسی را فعال کنید:
   - مسیر: **Settings → General → Site Language → فارسی (فارسی)**
   - اگر «فارسی» در لیست نبود، بسته زبان را از **Dashboard → Updates → Install translations** بگیرید.
3. ساختار پیوند یکتا را روی «نام نوشته» بگذارید:
   - **Settings → Permalinks → Post name** و ذخیره کنید.

## 🎨 گام ۲ — نصب قالب وردپرس «Effect Studio» و المنتور

### ۲.۱ نصب قالب اختصاصی (پیشنهادی) — دو روش

قالب `effect-studio` هدر و فوتر را **دقیقاً مطابق طراحی سایت** پیاده می‌کند و نیازی به Elementor Pro ندارید.

**روش ۱ — آپلود مستقیم ZIP (ساده‌تر):**
1. فایل `wordpress/effect-studio.zip` را از **Appearance → Themes → Add New → Upload Theme** آپلود و نصب کنید.
2. قالب **Effect Studio** را فعال کنید.

**روش ۲ — آپلود دستی:**
1. پوشه `wordpress/theme/effect-studio/` را در مسیر `wp-content/themes/` هاست آپلود کنید.
2. از **Appearance → Themes** قالب **Effect Studio** را فعال کنید.

**بعد از فعال‌سازی:**
- 🎉 **۹ صفحه سایت به‌صورت خودکار ساخته می‌شوند** (خانه، درباره ما، آکادمی، دوره، بلاگ، دسته‌بندی، نوشته، فروشگاه، محصول) و محتوای المنتور آن‌ها هم به‌صورت خودکار بارگذاری می‌شود (به شرطی که المنتور نصب و فعال باشد).
- صفحه نخست و صفحه نوشته‌ها (بلاگ) و منوی اصلی هم به‌صورت خودکار تنظیم می‌شوند.
- برای تنظیم رنگ برند، تلفن و ایمیل: **Appearance → Customize → تنظیمات برند اثر**.

> ⚠️ **ترتیب پیشنهادی:** ابتدا المنتور را نصب و فعال کنید، سپس قالب Effect Studio را فعال کنید تا محتوای صفحات به‌درستی بارگذاری شود. اگر اول قالب را فعال کردید، بعداً هم می‌توانید با غیرفعال/فعال‌کردن دوباره قالب، صفحات را مجدداً بسازید (یا از تنظیمات `effect_studio_pages_installed` صرف‌نظر کنید).

> 💡 اگر نمی‌خواهید از قالب اختصاصی استفاده کنید، می‌توانید قالب سبک **Hello Elementor** نصب کنید؛ اما در آن صورت هدر/فوتر را باید خودتان بسازید (یا با Elementor Pro Theme Builder).

### ۲.۲ نصب المنتور

1. المنتور (نسخه رایگان کافی است) را نصب و فعال کنید:
   - **Plugins → Add New → جستجوی "Elementor" → Install → Activate**

## 🌐 گام ۳ — فعال‌سازی راست‌چین (RTL) و فونت فارسی

1. **Customize → Additional CSS** (یا Elementor → Site Settings → Custom CSS) را باز کنید.
2. محتوای فایل `assets/effect-studio.css` را در آن جای‌گذاری کنید.
3. فونت فارسی **وزیرمتن به‌صورت محلی داخل قالب** قرار دارد و به‌صورت خودکار بارگذاری می‌شود — **نیازی به Google Fonts یا افزونه فونت نیست**.
   - فایل‌ها: `theme/effect-studio/assets/fonts/Vazirmatn-*.woff2`
   - اگر فونت دیگری (مثل ایران‌سنس) می‌خواهید، فایل woff2 آن را در همان پوشه بگذارید و تعریف `@font-face` را در `style.css` تغییر دهید.

## 🛒 گام ۳.۵ — فروشگاه با ووکامرس (اختیاری)

اگر فروشگاه واقعی (سبد خرید و پرداخت) می‌خواهید:

1. افزونه **WooCommerce** را نصب و فعال کنید.
2. قالب Effect Studio از ووکامرس پشتیبانی می‌کند (فایل `woocommerce.php` و استایل اختصاصی `assets/css/woocommerce.css`).
3. به‌صورت خودکار، اگر صفحه‌ای با اسلاگ `shop` وجود داشته باشد، به‌عنوان «صفحه فروشگاه» ووکامرس تنظیم می‌شود.
4. برای محصولات، از مسیر **Products → Add New** محصول بسازید؛ قالب `محصول` در این حالت با صفحه محصول ووکامرس جایگزین می‌شود.

> 💡 بدون ووکامرس هم، صفحات `فروشگاه` و `محصول` به‌صورت نمایشی (با المنتور) کار می‌کنند؛ اما برای سبد خرید واقعی، ووکامرس لازم است.

## 📥 گام ۴ — ایمپورت قالب‌ها در المنتور (اختیاری، در صورت عدم استفاده از نصب خودکار)

قالب‌های المنتور در این پکیج **فقط بدنه** هستند (هدر و فوتر ندارند) تا با هدر/فوتر قالب وردپرس تداخل نکنند.

1. مسیر: **Templates → Saved Templates → Import Templates**
2. هر ۹ فایل JSON را یک‌جا انتخاب و ایمپورت کنید.
3. یک «صفحه» جدید بسازید (Pages → Add New)، سپس **Edit with Elementor** را بزنید.
4. در المنتور: آیکون پوشه (Add Template) → تب **My Templates** → قالب موردنظر را انتخاب و Insert کنید.

> ℹ️ اگر از «نصب خودکار» در گام ۲ استفاده کرده باشید، نیازی به این گام ندارید؛ محتوای صفحات از قبل بارگذاری شده است.

## 🔗 گام ۵ — اتصال صفحات (لینک‌ها)

در قالب‌ها لینک‌های داخلی به‌صورت اسلاگ نسبی نوشته شده‌اند. بعد از ساخت صفحات، این‌ها را با لینک واقعی صفحات خودتان جایگزین کنید (یا از Dynamic Tag → Internal URL در المنتور استفاده کنید):

| صفحه | اسلاگ پیشنهادی | فایل قالب |
|---|---|---|
| صفحه اصلی | `/` | effect-studio-home.json |
| درباره ما | `/about-us/` | effect-studio-about-us.json |
| آکادمی | `/academy/` | effect-studio-academy.json |
| دوره | `/academy/course/` | effect-studio-course.json |
| بلاگ | `/blog/` | effect-studio-blog.json |
| دسته‌بندی | `/category/technology/` | effect-studio-category.json |
| نوشته | `/blog/hyundai-elantra-2027/` | effect-studio-post.json |
| فروشگاه | `/shop/` | effect-studio-shop.json |
| محصول | `/shop/pegboard/` | effect-studio-product.json |

> 💡 ساده‌ترین راه برای جایگزینی همه‌ی لینک‌ها: در ویرایشگر المنتور، روی هر دکمه/لینک کلیک کنید و در پنل سمت چپ، فیلد Link را به آدرس صفحه‌ی مربوطه تغییر دهید.

## 🖼 گام ۶ — لوگو و تصاویر

- لوگوی برند در `assets/logo.png` و `assets/logo.webp` موجود است.
- آن را در **Media → Add New** آپلود کنید و در ویجت Image هدر (که فعلاً با `LOGO_URL` مشخص شده) جایگزین کنید.
- سایر تصاویر (نمونه‌کارها، اسلایدرها، عکس محصولات و دوره‌ها) را از فایل‌های HTML اصلی یا نسخه‌ی زنده‌ی سایت بردارید و در Media آپلود کنید.

## 📝 گام ۷ — منوی ناوبری (اختیاری اما پیشنهادی)

1. مسیر: **Appearance → Menus**
2. یک منو بسازید و این آیتم‌ها را اضافه کنید:
   استودیو اثر، درباره ما، خدمات اثر، بلاگ، فروشگاه، ارتباط با ما.
3. در المنتور، ویجت **Nav Menu** را جایگزین لینک‌های متنی هدر کنید و این منو را انتخاب کنید تا مدیریت آیتم‌ها از پیشخوان وردپرس انجام شود.

## 🧰 نکات تکمیلی

- **رنگ‌های برند** (برای هماهنگی سراسری):
  - بنفش اصلی: `#4a00a5`
  - بنفش تیره (هدر/فوتر): `#2d0065`
  - کهربایی (CTA): `#ffaa00`
  - متن اصلی: `#16161d`
- **فونت:** وزیرمتن (Vazirmatn) — به‌صورت محلی داخل قالب (بدون نیاز به Google Fonts)
- **ترجمه:** فایل‌های `languages/effect-studio.pot` (الگو) و `fa_IR.po/.mo` (ترجمه فارسی) همراه قالب است و با فعال‌شدن زبان فارسی به‌صورت خودکار بارگذاری می‌شود.
- **ووکامرس:** قالب با ووکامرس هماهنگ است (فروشگاه، محصول، سبد خرید و پرداخت با استایل برند).
- **تصاویر واقعی:** تصاویر کلیدی (دوره‌ها، محصول، تیم، نقشه، گواهینامه و خدمات) از فایل‌های HTML اصلی استخراج و داخل قالب‌های المنتور قرار گرفته‌اند.
- **جایگزین بدون المنتور:** اگر المنتور فعال نباشد، صفحات یک نسخه متنی ساده نمایش می‌دهند (خالی نمی‌مانند).
- **پیکسل‌پرفکت داخل وردپرس:** قالب «پیکسل‌پرفکت (فایل HTML اصلی)» در ویرایشگر برگه‌ها موجود است که فایل HTML اصلی را خام سرو می‌کند (نیاز به قراردادن فایل‌ها در پوشه `frozen/` قالب دارد — راهنما داخل همان پوشه است).
- برای دوره‌ها و ثبت‌نام، می‌توانید از افزونه‌های LMS مانند **LearnPress** یا **Tutor LMS** استفاده کنید.
