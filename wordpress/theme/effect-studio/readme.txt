قالب اختصاصی «استودیو اثر» — راست‌چین، سبک و سازگار با المنتور.

== Description ==

قالب Effect Studio یک قالب وردپرس راست‌چین (RTL) است که مخصوص سایت «استودیو اثر» طراحی شده و به‌صورت کامل با المنتور سازگار است.

ویژگی‌ها:

* هدر و فوتر اختصاصی مطابق طراحی برند
* پشتیبانی کامل از زبان فارسی و RTL
* فونت وزیرمتن (Vazirmatn)
* پالت رنگ برند (بنفش و کهربایی) با قابلیت تغییر از سفارشی‌ساز
* منوی ناوبری با زیرمنوی کشویی
* سازگار با المنتور (و Elementor Pro Theme Builder)
* سبک و بهینه

== Installation ==

1. پوشه `effect-studio` را در مسیر `wp-content/themes/` آپلود کنید.
2. از پیشخوان وردپرس به Appearance → Themes بروید و قالب Effect Studio را فعال کنید.
3. از Appearance → Customize رنگ‌ها، شماره تلفن و ایمیل را تنظیم کنید.
4. از Appearance → Menus منوی اصلی را بسازید و به موقعیت «منوی اصلی» اختصاص دهید.

== Frequently Asked Questions ==
